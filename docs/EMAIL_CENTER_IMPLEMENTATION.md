后续所有开发、配置、联调和部署，都必须按本文档中的阶段顺序推进。每完成一项工作，都要同步更新本文档中的状态标记。

## 2. 安全规则

以下敏感信息不得写入本文档、前端代码、截图、提交说明或公开日志：
- 数据库地址、数据库账号、数据库密码
- Resend API Key / SMTP 凭据
- 服务器登录凭据
- JWT 密钥、加密密钥、API Key

敏感信息只能放在服务端环境变量或服务器私有配置中。

## 3. 项目目标

- 构建一个内部使用的邮件中心后台。
- 支持你自己的后台和其他项目通过 API 调用发信。
- 使用 `Node.js + PostgreSQL + Vue 3 + Vite + JavaScript`。
- 使用 `Resend SMTP` 发信，并固定 `465` 端口。
- 当前默认发件地址使用 `@email.pixris.online`。
- 管理台界面统一使用中文。
- 前端样式遵循最新 Element Plus 默认风格。
- 附件存储路径使用相对路径，兼容 Linux 服务器部署。
- 内部 API 支持仅传发送人、标题、接收人、内容的简化调用方式。
- 提供管理员账号创建脚本和操作文档。
- 支持多个发件人身份。
- 支持模板分类、模板审核、发送审批。
- 支持附件发送，单附件业务上限 `10MB`。
- 部署到腾讯云服务器，通过宝塔面板运维，域名为 `email.pixris.online`。
